# 编译器功能分析 - 当前支持 vs 缺失功能

- ✅ 加法：`+`
- ✅ 减法：`-`
- ✅ 乘法：`*`
- ✅ 除法：`/`

- ✅ 整数类型：`int`
- ✅ 浮点类型：`double`（部分支持，未完全测试）
- ✅ 变量声明：`int x;`
- ✅ 变量初始化：`int x = 5;`
- ✅ 变量赋值：`x = 10;`

### 3. 数组
- ✅ 一维数组声明：`int arr[3];`
- ✅ 一维数组访问：`arr[0]`

- ✅ 打印语句：`print(x);`

### 5. 优化
- ✅ 常量折叠
- ✅ 常量传播

## ❌ 缺失的基本功能（按重要性排序）

### 🔴 高优先级（基础运算）

#### 1. **取模运算符**
- ❌ 取模：`%`
- 示例：`int r = 10 % 3;  // r = 1`
- 难度：⭐ 容易
- MIPS指令：`div` + `mfhi`（获取余数）

#### 2. **比较运算符**
- ❌ 等于：`==`
- ❌ 不等于：`!=`
- ❌ 大于：`>`
- ❌ 小于：`<`
- ❌ 大于等于：`>=`
- ❌ 小于等于：`<=`
- 示例：`int x = (a > b);`
- 难度：⭐⭐ 中等
- MIPS指令：`slt`, `seq`, `sne`, `sgt`, `sge`, `sle`

#### 3. **逻辑运算符**
- ❌ 逻辑与：`&&`
- ❌ 逻辑或：`||`
- ❌ 逻辑非：`!`
- 示例：`int x = (a > 5 && b < 10);`
- 难度：⭐⭐ 中等
- 需要短路求值（short-circuit evaluation）

#### 4. **位运算符**
- ❌ 按位与：`&`
- ❌ 按位或：`|`
- ❌ 按位异或：`^`
- ❌ 按位取反：`~`
- ❌ 左移：`<<`
- ❌ 右移：`>>`
- 示例：`int x = a & 0xFF;`
- 难度：⭐ 容易
- MIPS指令：`and`, `or`, `xor`, `nor`, `sll`, `srl`, `sra`

#### 5. **一元运算符**
- ❌ 负号（取反）：`-x`
- ❌ 正号：`+x`
- ❌ 自增：`++` (前置和后置)
- ❌ 自减：`--` (前置和后置)
- 示例：`x++; --y; int z = -a;`
- 难度：⭐⭐ 中等

---

### 🟡 中优先级（控制流）

#### 6. **条件语句**
- ❌ if语句：`if (condition) { ... }`
- ❌ if-else语句：`if (condition) { ... } else { ... }`
- ❌ else-if链：`if {...} else if {...} else {...}`
- 难度：⭐⭐⭐ 较难
- 需要：条件跳转、标签生成

#### 7. **循环语句**
- ❌ while循环：`while (condition) { ... }`
- ❌ for循环：`for (init; cond; incr) { ... }`
- ❌ do-while循环：`do { ... } while (condition);`
- 难度：⭐⭐⭐ 较难
- 需要：跳转指令、标签管理

#### 8. **控制语句**
- ❌ break语句
- ❌ continue语句
- ❌ return语句
- 难度：⭐⭐ 中等

---

### 🟢 低优先级（高级特性）

#### 9. **函数**
- ❌ 函数定义：`int add(int a, int b) { return a + b; }`
- ❌ 函数调用：`result = add(5, 3);`
- ❌ 函数参数传递
- ❌ 返回值
- 难度：⭐⭐⭐⭐ 困难
- 需要：栈帧管理、调用约定

#### 10. **复合赋值运算符**
- ❌ `+=`, `-=`, `*=`, `/=`, `%=`
- ❌ `&=`, `|=`, `^=`, `<<=`, `>>=`
- 示例：`x += 5;` 等价于 `x = x + 5;`
- 难度：⭐ 容易

#### 11. **三元运算符**
- ❌ 条件表达式：`condition ? true_val : false_val`
- 示例：`int max = (a > b) ? a : b;`
- 难度：⭐⭐ 中等

#### 12. **指针**
- ❌ 指针声明：`int *p;`
- ❌ 取地址：`&x`
- ❌ 解引用：`*p`
- 难度：⭐⭐⭐⭐ 困难

#### 13. **结构体**
- ❌ 结构体定义：`struct Point { int x; int y; };`
- ❌ 成员访问：`point.x`
- 难度：⭐⭐⭐⭐ 困难

#### 14. **字符串**
- ❌ 字符串字面量：`"Hello"`
- ❌ 字符类型：`char`
- ❌ 字符串操作
- 难度：⭐⭐⭐ 较难

## 🎯 建议：下一步应该添加什么？

根据你的需求"加入新的基本运算功能"，我建议按以下顺序添加：

### 最容易实现的3个功能：

#### 1️⃣ **取模运算符 `%`** （最简单，15-30分钟）
```c
int remainder = 10 % 3;  // remainder = 1
```
- 只需在parser.y、codegen.c中添加几行代码
- MIPS: `div` + `mfhi`

#### 2️⃣ **一元负号运算符 `-x`** （简单，30分钟）
```c
int x = 5;
int y = -x;  // y = -5
```
- 需要添加新的AST节点类型 `NODE_UNARY`
- MIPS: `sub $t0, $zero, $t1`

#### 3️⃣ **位运算符 `&`, `|`, `^`, `~`, `<<`, `>>`** （简单，1小时）
```c
int a = 5 & 3;     // 按位与
int b = 5 | 3;     // 按位或
int c = 5 ^ 3;     // 按位异或
int d = ~5;        // 按位取反
int e = 5 << 2;    // 左移
int f = 5 >> 1;    // 右移
```
- MIPS已有对应指令，很容易实现
