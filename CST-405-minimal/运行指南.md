# CST-405 编译器项目 - 运行指南

## 📋 项目简介

这是一个**教育性的C编译器**，用于演示编译器的完整工作流程。它实现了一个简化版的C语言编译器，将源代码编译成MIPS汇编代码。

### 🎯 项目特点

- **完整的5阶段编译流程**：
  1. 词法分析（Lexer - Flex）
  2. 语法分析（Parser - Bison）
  3. AST构建（抽象语法树）
  4. 中间代码生成（TAC - 三地址码）
  5. 目标代码生成（MIPS汇编）

- **支持的语言特性**（简化版C语言）：
  - ✅ 整数变量声明：`int x;`
  - ✅ 变量初始化：`int x = 5;`
  - ✅ 赋值语句：`x = 10;`
  - ✅ 四则运算：`+`, `-`, `*`, `/`
  - ✅ 打印语句：`print(x);`
  - ✅ 一维数组：`int arr[3];` 和 `arr[0] = 10;`
  - ✅ 二维数组：`int matrix[2][2];` 和 `matrix[0][1] = 5;`

## 🚀 快速开始

### 1. 编译编译器本身

```bash
make
```

这会生成可执行文件 `minicompiler`

### 2. 编译你的C代码

```bash
./minicompiler <输入文件.c> <输出文件.s>
```

例如：
```bash
./minicompiler simple_test.c output.s
```

### 3. 快速测试

```bash
make test
```

这会自动编译 `test.c` 并显示生成的汇编代码

### 4. 清理生成的文件

```bash
make clean
```

## 📖 编译流程详解

### 阶段1：词法分析（Scanner）
- **文件**: `scanner.l`
- **功能**: 将源代码分解成tokens（标记）
- **示例**: `int x = 10;` → `[INT, ID(x), =, NUM(10), ;]`

### 阶段2：语法分析（Parser）
- **文件**: `parser.y`
- **功能**: 根据语法规则构建抽象语法树（AST）
- **输出**: 树状结构表示程序结构

### 阶段3：中间代码生成（TAC）
- **文件**: `tac.c`
- **功能**: 生成三地址码（每条指令最多3个操作数）
- **示例**: `y = x + 5` → `t0 = x + 5; y = t0`

### 阶段4：代码优化
- **功能**: 
  - 常量折叠（Constant Folding）
  - 常量传播（Constant Propagation）
- **示例**: `t0 = 10 + 5` → `t0 = 15`

### 阶段5：MIPS代码生成
- **文件**: `codegen.c`
- **功能**: 将TAC转换为MIPS汇编指令
- **输出**: 可在MIPS模拟器中运行的`.s`文件

## ⚠️ 当前限制

1. **仅支持整数类型** - 浮点数功能部分实现但未完全集成
2. **不支持**：
   - 循环（for, while）
   - 条件语句（if/else）
   - 函数定义
   - 指针
   - 字符串
